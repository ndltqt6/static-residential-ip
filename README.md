## 三步识别真假静态住宅IP

验证一个静态住宅 IP 的真假，核心看两件事——ASN 归属和欺诈分，再加一条价格常识。

1. **查 ASN 归属。** 用 IPinfo 查拿到手的 IP，Type 字段必须是 `isp`，ASN 归属要是当地电信运营商（比如 AT&T、Verizon、Comcast 这类）。显示 hosting 或 business 的，就是机房 IP 换皮。
2. **查欺诈分。** 用 Scamalytics 扫 Fraud Score，合格的静态住宅 IP 欺诈分应控制在 10 分以下。分数偏高的 IP 挂长期账号，风险会明显变大。
3. **用价格常识过滤。** 远低于市场区间的“静态住宅IP”——尤其是社交平台和个人卖家手里的低价货——很多是多人共用同一出口的共享 IP，一人滥用、全员连坐。

还有一条容易被忽略：确认 IP 来源合法。部分低价“住宅IP”并非服务商向运营商正规申请的 IP 段，而是通过灰色 SDK 占用真实用户设备的网络出口。这种来源一旦出问题，被牵连风控的是挂在上面的你的账号，下单前值得向服务商问一句 IP 获取方式是否可追溯。

## 常见问题

### 静态住宅IP会自动轮换吗？

不会。静态的核心特点就是在整个租用周期内保持同一个出口 IP。任务需要频繁换 IP 的话，该看的是动态住宅产品，两者别买反。

### Fraud Score 越低就一定越好吗？

不一定。欺诈分只是风控数据库里的一个维度，还要结合 ASN、运营组织、地理位置和实际连接表现一起判断，不同数据库给出的分类也可能不一致。拿到 IP 后先核对归属信息，再用真实业务做小规模连接测试，比只盯着一个分数靠谱。

### 固定IP就能保证账号安全吗？

不能这么理解。固定出口只是让网络环境保持一致，账号安全还取决于设备指纹、浏览器环境、时区和操作习惯，并且要遵守平台本身的规则。把“固定 IP”当成绕过风控的万能钥匙，是这类产品最常见的使用误区。

### 家宽VPS在国内直连会慢吗？

会有延迟，日常操作一般不至于没法用。对速度要求高的业务，常规做法是配一台中转服务器或加速线路，这也是家宽 VPS 用户的通行方案。
